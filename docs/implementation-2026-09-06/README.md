# Реализация монитора депозитов · 6 сентября 2026

Первая рабочая версия после согласования прототипа. Приложение остаётся локальным монитором биржевых средств. Подписки, сервер и публикация не добавлялись.

## Что изменено

**Интерфейс.** Обзор / Биржи / Статистика, фильтр биржи, несколько аккаунтов, периоды и вся доступная история, рост/уменьшение в сумме и процентах, вклад аккаунтов с одинаковыми границами периода, раскрытие кошельков. Светлая/тёмная/системная тема, RU/EN/AR, RTL, скрытие сумм, подписи кнопок для доступности, выбор точки графика. Демо изолировано от реальных записей.

**Достоверность.** Store координирует загрузку, а нормализация и оценка вынесены в `observations.ts`. Повторная загрузка заменяет Earn; реальные нули/отрицательная equity сохраняются; запросы ограничены по времени, ошибки envelope проверяются. Неизвестная цена или недоступный кошелёк имеют отдельный статус. При ошибке сохраняется последнее наблюдение, но новый полный снимок не создаётся. Для каждого аккаунта сохраняется время последней полной загрузки, в том числе после перезапуска. Одновременные обновления объединяются.

Расчёты используют decimal.js; валютные единицы указаны явно. USD equity Bybit/OKX переводится в USDT по публичному курсу Coinbase; отсутствие курса не заменяется единицей. Номинал фьючерсной позиции не прибавляется к средствам. USDC оценивается по рыночному курсу.

**Статистика потоков.** Добавлен журнал пополнений/выводов. Пока операции вносятся вручную. Результат без потоков показывается после явного подтверждения пользователем полноты для точных дат и выбранных аккаунтов. Это не процентная инвестиционная доходность. После изменения журнала подтверждение сбрасывается. Для собственных переводов нужны обе стороны с одинаковым principal; комиссии остаются в разнице капитала. Автоматического сопоставления переводов и импорта операций пока нет.

**Защита.** AES-GCM для истории, метаданных, кеша и архива; случайные ключ/nonce создаёт системный генератор Expo Crypto. Ключ шифрования хранится в SecureStore с привязкой к устройству, имя записи привязано как authenticated data. При повреждении ciphertext или потере ключа данные не сбрасываются автоматически. Операции сохранения сериализованы; частичные создание/удаление оставляют запись для восстановления. UI не отображает сырые сетевые исключения с подписанными URL.

В native добавлены разблокировка устройства и защита фонового превью. На Android FLAG_SECURE также ограничивает снимки экрана; это нужно проверить на целевых устройствах. JSON-экспорт открывает системный выбор получателя, не содержит API-ключей и удаляет временный файл после завершения. Автоматическое восстановление экспорта пока отсутствует.

**Терминал.** Удалены модули торговли, создание/отмена ордеров, изменение плеча/режима и торговые компоненты. Старый маршрут перенаправляет в настройки. Старые планы сохраняются полностью в зашифрованном архиве, а UI показывает инструмент и идентификаторы ордеров. Миграция не обращается к бирже и не отменяет ордера.

## Реальное покрытие

| Биржа | Состав расчёта | Ограничение |
|---|---|---|
| Binance | API wallet/balance с quoteAsset=USDT | Полнота зависит от кошельков, возвращённых этим endpoint |
| Bybit | Wallet equity, отдельный Funding, Flexible Saving и OnChain Earn | Другие Earn-продукты не реализованы; pending Earn помечается неполным. Обнаруженный Classic обрабатывается консервативно; реальное покрытие режимов требует сверки |
| BingX | Spot, включая оценку монет, и Futures equity | Earn пока не включён; предупреждение есть на обзоре и в деталях |
| OKX | Trading equity и Funding с оценкой монет | Earn пока не включён; предупреждение есть на обзоре и в деталях |
| Gate.io | Total balance и его breakdown в запрошенной валюте | Несогласованные суммы/единицы отклоняются; подтверждённый пустой счёт даёт ноль |

Полный успешный снимок означает успешное чтение **поддерживаемого набора кошельков**, а не обещание охватить любой новый продукт биржи. Неподдерживаемые продукты нельзя рекламировать как учтённые. Поддержку региональных endpoint необходимо расширять и проверять отдельно; сейчас используются прежние глобальные адреса адаптеров.

Bybit totalEquity действительно выражен в USD; используются требования к equity из [официальной документации](https://bybit-exchange.github.io/docs/v5/account/wallet-balance). Семантика Earn principal/накопленной прибыли и pending проверена по [Get Staked Position](https://bybit-exchange.github.io/docs/v5/finance/earn/easy-onchain/position). Публичный валютный endpoint не требует ключей: [Coinbase Exchange Rates](https://docs.cdp.coinbase.com/coinbase-app/track-apis/exchange-rates).

- Старые аудитные probes сохранены в `../audit-2026-09-06/reproductions.before.ts.txt`; исполняемый файл аудита теперь запускает регрессионные ожидания исправленного поведения.

## Проверки и границы

На текущей реализации прошли **39 тестов** в шести файлах, `tsc`, lint и проверка совместимости Expo. Проверены синтетические случаи 48 620 / +3620 / +1620 и Bybit за неделю −200 / −400. Получены production bundles для iOS, Android и web. Браузерная проверка включает демо, фильтры, отрицательную статистику, скрытие сумм, раскрытие кошельков, светлую/тёмную темы, RU/EN/AR и RTL. На ширине 320 и 736 px горизонтального переполнения не обнаружено. Старый маршрут терминала открывает настройки; на web отсутствует форма настоящих API-ключей.

Проверка реальных read-only ключей, сверка с интерфейсами всех пяти бирж, биометрия/переустановка/фон на физических устройствах и распространение через магазины не выполнялись. Арабский перевод требует вычитки носителем.

После совместимых patch-обновлений Expo отчёт npm audit уменьшился с 33 до 31 затронутого пакета; это не означает устранение всех достижимых уязвимостей. Остаются 13 high и 18 moderate, critical — 0. Актуальный сырой отчёт сохранён рядом в `npm-audit.json`. Major-обновления SDK и оставшиеся advisory требуют отдельного разбора до платного выпуска.
