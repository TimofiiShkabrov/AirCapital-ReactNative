Locale: sk

## App name

## Short description

Sledujte zostatky na burzách, históriu portfólia a zmeny kapitálu.

## Full description

Vaše kryptomeny sú na rôznych burzách. Prehľad o nich môžete mať na jednom mieste.

AirCapital spája zostatky z Binance, Bybit, OKX, BingX a Gate.io do prehľadného zobrazenia. Kontrolujte celkovú hodnotu portfólia, porovnávajte účty a sledujte vývoj svojho kapitálu.

• Zostatky a rozdelenie aktív podľa účtov
• História portfólia, rast aj poklesy
• Vklady a výbery popri zmenách zostatku
• Štatistiky a porovnávanie období
• Demo s fiktívnymi údajmi bez pripojenia burzy

Pripojte API kľúče s oprávnením iba na čítanie. Sú bezpečne uložené vo vašom zariadení. Biometrická ochrana a analýza používania sú voliteľné. Zostatky a API kľúče sa neposielajú do Analytics.

AirCapital slúži na sledovanie: neobchoduje, nezadáva výbery a nedrží vaše prostriedky. Rozsah a dostupnosť údajov závisia od API jednotlivých búrz.

Rozhranie podporuje 31 jazykov. Pri prvom spustení vyberie podporovaný jazyk zariadenia, inak angličtinu.
