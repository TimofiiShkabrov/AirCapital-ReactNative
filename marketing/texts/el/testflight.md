## Beta app description

Τα κρυπτονομίσματά σου βρίσκονται σε διάφορα ανταλλακτήρια. Η εικόνα τους μπορεί να είναι συγκεντρωμένη.

Το AirCapital συγκεντρώνει υπόλοιπα από Binance, Bybit, OKX, BingX και Gate.io σε μια ξεκάθαρη προβολή. Δες τη συνολική αξία του χαρτοφυλακίου σου, σύγκρινε λογαριασμούς και παρακολούθησε την εξέλιξη του κεφαλαίου σου.

• Υπόλοιπα και κατανομή περιουσιακών στοιχείων ανά λογαριασμό
• Ιστορικό χαρτοφυλακίου, άνοδος και πτώση
• Καταθέσεις και αναλήψεις μαζί με τις αλλαγές υπολοίπου
• Στατιστικά και σύγκριση περιόδων
• Επίδειξη με εικονικά δεδομένα χωρίς σύνδεση ανταλλακτηρίου

Σύνδεσε κλειδιά API μόνο για ανάγνωση, τα οποία αποθηκεύονται με ασφάλεια στη συσκευή σου. Η βιομετρική προστασία και η ανάλυση χρήσης είναι προαιρετικές. Υπόλοιπα και κλειδιά API δεν αποστέλλονται στο Analytics.

Το AirCapital είναι εργαλείο παρακολούθησης. Δεν πραγματοποιεί συναλλαγές ή αναλήψεις και δεν φυλάσσει χρήματα. Η κάλυψη και η διαθεσιμότητα των δεδομένων εξαρτώνται από το API κάθε ανταλλακτηρίου.

Το περιβάλλον υποστηρίζει 31 γλώσσες. Κατά την πρώτη εκκίνηση επιλέγεται υποστηριζόμενη γλώσσα της συσκευής ή, διαφορετικά, τα αγγλικά.
