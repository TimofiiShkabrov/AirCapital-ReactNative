## Full description

أصولك المشفرة موزّعة على منصات مختلفة. ويمكنك متابعتها من مكان واحد.

يجمع AirCapital أرصدتك من Binance وBybit وOKX وBingX وGate.io في عرض واضح. اطّلع على القيمة الإجمالية لمحفظتك، وقارن الحسابات، وتابع تغيرات رأس مالك.

• الأرصدة وتوزيع الأصول حسب الحساب
• سجل المحفظة والارتفاعات والانخفاضات
• الإيداعات والسحوبات إلى جانب تغيرات الرصيد
• إحصائيات ومقارنة بين الفترات
• عرض توضيحي ببيانات افتراضية دون ربط منصة

اربط مفاتيح API بصلاحية القراءة فقط، وتُحفظ بأمان على جهازك. الحماية بالمصادقة البيومترية وتحليلات الاستخدام اختياريتان. لا تُرسَل الأرصدة أو مفاتيح API إلى Analytics.

AirCapital أداة للمتابعة: لا ينفّذ تداولات، ولا يبدأ عمليات سحب، ولا يحتفظ بأموالك. يعتمد نطاق البيانات وتوفرها على واجهة API لكل منصة.
