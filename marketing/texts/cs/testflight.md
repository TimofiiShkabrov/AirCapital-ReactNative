# AirCapital · TestFlight · cs

Locale: cs

## Beta app description

Vaše kryptoměny jsou na různých burzách. Přehled o nich můžete mít na jednom místě.

AirCapital spojuje zůstatky z Binance, Bybit, OKX, BingX a Gate.io do přehledného zobrazení. Kontrolujte celkovou hodnotu portfolia, porovnávejte účty a sledujte vývoj svého kapitálu.

• Zůstatky a rozložení aktiv podle účtů
• Historie portfolia, růst i poklesy
• Vklady a výběry vedle změn zůstatku
• Statistiky a porovnávání období
• Demo s fiktivními daty bez připojení burzy

Připojte API klíče s oprávněním pouze pro čtení. Jsou bezpečně uložené ve vašem zařízení. Biometrická ochrana i analýza používání jsou volitelné. Zůstatky a API klíče se do Analytics neodesílají.

AirCapital slouží ke sledování: neobchoduje, nezadává výběry a nedrží vaše prostředky. Rozsah a dostupnost dat závisí na API jednotlivých burz.

Rozhraní podporuje 31 jazyků. Při prvním spuštění vybere podporovaný jazyk zařízení, jinak angličtinu.
